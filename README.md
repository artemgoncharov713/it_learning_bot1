# IT Learning Bot

Telegram-бот для поиска и сохранения учебных материалов по дисциплинам и темам.

Проект выполнен в рамках учебной программы. Целевая аудитория — студенты первого курса техникума.

---

## Назначение

Бот помогает студентам:

- просматривать каталог учебных дисциплин, тем и материалов;
- открывать материалы по ссылкам (документация, статьи, видеоуроки);
- искать материалы по названию;
- сохранять полезные материалы в избранное (у каждого пользователя — свой список).

Дополнительно реализована **панель администратора** для управления каталогом: добавление, редактирование и удаление дисциплин, тем и материалов.

---

## Основные функции

### Для студента

- 📚 **Учебные материалы** — каталог: дисциплины → темы → материалы.
- 🔍 **Поиск материалов** — по названию.
- ⭐ **Избранное** — сохранение и удаление материалов, отдельно для каждого пользователя.
- ℹ️ **О боте** — информация о проекте.
- 📺 Ссылки на видеоуроки в Telegram-канале.

### Для администратора

- 📚 Управление дисциплинами (добавить / изменить / удалить).
- 📖 Управление темами (с привязкой к дисциплине).
- 📄 Управление материалами: название, тип, ссылка, описание, видео-ссылка, файл.
- 📎 Загрузка файлов к материалам (PDF, DOCX и т.п.).
- 👨‍🏫 Админ-панель доступна только пользователям из списка `ADMIN_IDS`.

## Технологии

- **Python 3.12**
- **aiogram 3.x** — асинхронная библиотека для Telegram Bot API
- **SQLite3** — хранение каталога и избранного
- **python-dotenv** — чтение переменных окружения
- **Git / GitHub** — контроль версий

---

## Требования для запуска

- Python 3.10 или выше (рекомендуется 3.12)
- pip
- Git (для клонирования репозитория)
- Аккаунт Telegram и бот, созданный через [@BotFather](https://t.me/BotFather)
